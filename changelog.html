v1.1.0 (Oct. 18th, 2026)

Changes include:

  • Accurate running clock that will not buffer if scoreboard communication is slow.
  • Splits can now be defined and changed for custom split layouts.
  • Fixed a buffering issue that led to delayed writing of photo finish images.
  • If you end the race accidentally or have a technical difficulty, you can now reload a race from its original start time.
  • You can now opt to assign times from athletes' bib numbers instead of the lanes they are running in.

v1.0.0 (Sep. 13th, 2026)

  • First public release of PhotoFinishPro Fully Automatic Timing.
  • Track & Field Timing Functionality
  • Limited Cross Country Timing Functionality. Expanded XC functionality is planned for a future update.
