Changelog

v1.1.0 (Oct. 18th, 2026)

• PhotoFinishPro Fully Automatic Timing v1.1.0 is now done!

• Changes include:

• Accurate Running Clock that will not buffer if scoreboard communication is slow.

• Splits can now be defined and changed for custom split layouts.

• Camera buffering has been fixed.

• If you end the race accidentally or have a technical difficulty, you can now reload a race from it's original start time..

• You can now opt to assign times from athlete's bib numbers instead of the lanes they are running in.
