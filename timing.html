How We Time Meets:

Meets are seeded through AthleticNET.

Coaches submit their athletes to AthleticNET.

We download the start lists from AthleticNET and put them into our custom timing software.

We select the event which imports the start list for that event into our photo review system.

The start trigger device picks up the volume from the starting gun. This sends a command to the photo review system to start the race.

Once runners get close to the finish chute, we start the capture on the line scan camera. This camera takes a lot of pictures of the finish line that are one pixel wide and arranges them by time, creating a photo finish picture.
